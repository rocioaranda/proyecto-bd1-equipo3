# 📁 Sección de Documentación (`docs/`)

Bienvenido a la documentación general del proyecto **Byte Motors**. Esta sección se divide en 5 etapas que detallan todo el ciclo de vida del desarrollo del sistema de base de datos relacional.

---

## 🧭 Estructura de Etapas

### 📄 [Etapa 01: Requerimientos y Alcance](./etapa-01/README.md)
Define la problemática de negocio, el alcance de la solución, los actores del sistema y las reglas de negocio aplicadas.
* Archivos: `descripcion del caso.md`, `Reglas-negocio.md`, `alcance.md`.

### 📄 [Etapa 02: Modelado de Datos](./etapa-02/README.md)
Explica la evolución del diseño conceptual y lógico, diagramas DER, modelo relacional y la justificación de la normalización.
* Archivos: `decisiones_de_diseño.md`, `normalizacion_de_base_de_datos.md` y la carpeta `Der/` (versiones V1, V2 y V3).

### 📄 [Etapa 03: Implementación del Modelo Físico](./etapa-03/README.md)
Detalla la traducción del modelo lógico a SQL Server, restricciones (`CHECK`, `FOREIGN KEY`, `NOT NULL`) e integridad de datos.
* Archivos: Guía de implementación del esquema físico.

### 📄 [Etapa 04: Consultas SQL e Informes](./etapa-04/README.md)
Documenta las consultas comerciales, comprobantes de venta e informes analíticos desarrollados.
* Archivos: `comprobante_venta.md`, `consulta_avanzada.md`, `casos_de_uso.md`, `informe_de_ventas.md`.

### 📄 [Etapa 05: Mecanismos Técnicos Avanzados](./etapa-05/README.md)
Documentación técnica sobre procedimientos almacenados, funciones UDF, triggers de auditoría, seguridad (usuarios/roles), transacciones e índices.
* Archivos: Guías explicativas y demostraciones de objetos avanzados.
