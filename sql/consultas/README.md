# 🔍 Scripts SQL: Consultas y Reportes 

Este directorio contiene las consultas SQL encargadas de extraer información estratégica para el negocio.

---

## 📜 Archivos Disponibles

- 📄 [comprobante_venta.sql](./comprobante_venta.sql): Genera el detalle formateado para el comprobante de compra de un cliente.
- 📈 [consulta_de_negocio_de_analisis_de_clientes.sql](./consulta_de_negocio_de_analisis_de_clientes.sql): Análisis del comportamiento y acumulación de compras por cliente.
- 📊 [informe_ventas.sql](./informe_ventas.sql): Reporte global de facturación ordenado por vendedores y categorías.
- 🔍 [verificaciones.sql](./verificaciones.sql): Consultas de control para auditar el estado del stock y tablas del sistema.
