# 🏗️ Scripts SQL: Definición de Estructura DDL 

Este directorio contiene los scripts de Lenguaje de Definición de Datos (DDL) encargados de crear la base de datos, estructurar sus tablas y definir las restricciones de integridad del proyecto **Byte_Motors**.

---

## 📜 Archivos Disponibles

- 🏗️ [crear_BD.sql](./Crear_BD.sql): Script completo de creación de la base de datos `Byte_Motors`, definición de las 9 tablas del modelo relacional, claves primarias (`PRIMARY KEY`), claves foráneas (`FOREIGN KEY`) con reglas de borrado, y restricciones de dominio (`CHECK`, `UNIQUE`, `DEFAULT`, `NOT NULL`).
